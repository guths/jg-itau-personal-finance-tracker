# Plano 3 — Web (upload, perguntas, dashboard)

> Execução em lote: um implementador faz as tarefas em ordem, um commit por tarefa; uma revisão ao final.

**Goal:** app web em `web/` que consome a API do plano 2: importar PDFs, responder perguntas num chat item a item, dashboards de gastos, tabela de lançamentos e edição de categorias/regras.

**Spec:** `docs/superpowers/specs/2026-09-26-finance-tracker-design.md` §12 (contrato da API) e §13 (telas) são vinculantes. O contrato real da API está em `backend/internal/api/` — leia os handlers/DTOs e use exatamente os mesmos nomes de campos (snake_case).

**Tech:** Vite + React 19 + TypeScript (strict) + Tailwind CSS v4 + shadcn/ui (CLI `npx shadcn@latest`; charts do shadcn sobre Recharts) + TanStack Query v5 + React Router v7 + lucide-react + sonner. npm. Vitest para lógica pura.

## Global Constraints
- Textos da UI em pt-BR; moeda com `Intl.NumberFormat('pt-BR', {style:'currency', currency:'BRL'})` a partir de centavos (nunca somar floats: somar centavos inteiros e formatar no fim).
- Dev: Vite em 5173 com proxy `/api` → `http://127.0.0.1:8080`. Makefile: `web` (npm run dev), `web-build`.
- Tema claro/escuro do shadcn funcionando; layout responsivo (usável em ~375 px de largura).
- Cores das categorias vêm da API (`color`); gráficos com contraste legível nos dois temas, eixos e tooltips formatados em BRL.
- Nenhum dado real versionado. Commits `tipo(escopo): descrição pt-BR` + trailer Co-Authored-By do seu modelo.
- Portões de cada commit: `npm run build` (inclui `tsc`) e `npm run lint` limpos; `npx vitest run` verde.

## Tarefas

### Task 1 — Scaffold e fundação
Vite React TS em `web/`, Tailwind v4, shadcn init, componentes base necessários (button, card, input, badge, table, tabs, select, command/combobox, dialog, dropdown-menu, sonner, skeleton, progress, chart, switch, tooltip). `src/lib/api.ts` (fetch tipado para todas as rotas da §12, erros `{error}` viram `Error` com a mensagem pt-BR), `src/lib/format.ts` (`formatBRL(cents)`, `formatMonth("2026-09") → "set/2026"`, datas dd/mm/aaaa) com testes Vitest, QueryClient, Router, layout com barra lateral (Dashboard, Importar, Perguntas com badge de pendentes, Lançamentos, Categorias e regras) e alternância de tema. Makefile `web`, `web-build`.

### Task 2 — Importar
Área de arrastar/soltar + seletor de arquivos (múltiplos PDFs), envio em um `POST /api/imports` multipart `files`, estado "Importando e categorizando…", um cartão por arquivo (conta, mês de referência, contagens novas/existentes, total, ✓ conferido / "já importado" / erro em destaque com a mensagem da API, avisos), resumo da categorização e botão "Responder N perguntas" → /perguntas. Lista de documentos já importados (`GET /api/documents`).

### Task 3 — Perguntas (chat)
Um card por vez, progresso "3 de 21", histórico das respostas acima como um chat. Card: chave/descrição, valor total, quantidade, datas, conta, categoria/cidade do banco, texto da pergunta do GPT. Ações: até 3 sugestões numeradas; "Outra categoria…" (combobox com busca por "Categoria › Subcategoria"); texto livre → `interpret` → mostrar interpretação para confirmar; campo apelido; switch "Lembrar nas próximas" (ligado); "Não é gasto" (transferência pra conta minha / ignorar); "Pular". Atalhos `1`–`3`, `Enter` confirma, `S` pula. Puladas voltam no fim. Botão "Sugerir de novo" quando houver perguntas sem sugestão. Aba "Automáticos": lançamentos `categorized_by=llm` agrupados por chave, com troca de categoria (escopo chave). Estado vazio amigável quando não há pendências.

### Task 4 — Dashboard
Seletor de mês (`GET /api/months`), `GET /api/dashboard?month=`. Ordem: indicadores (total do mês, variação vs média dos 3 meses anteriores, custo fixo, falta pagar — faturas a vencer + parcelas futuras) e aviso "N lançamentos sem categoria → responder"; gasto por categoria (barras horizontais ordenadas, clique expande subcategorias e lista lançamentos da subcategoria via `/api/transactions`); recorrentes (tabela com status ok/aumentou/ausente); falta pagar (barras por mês, 12 meses, empilhadas por cartão; lista de parcelados "faltam X de N"; faturas a vencer); evolução (barras empilhadas por categoria, 12 meses); top 10 estabelecimentos. Skeletons no carregamento, estado vazio quando não há dados.

### Task 5 — Lançamentos e Categorias/regras
Lançamentos: tabela com filtros (mês, conta, categoria, tipo, texto, só sem categoria) e troca de categoria na linha com escolha "só este" / "todos desta chave". Categorias e regras: criar/renomear/arquivar categorias e subcategorias, cor da categoria; tabela de regras com edição (subcategoria, tipo, modo, apelido, recorrente) e exclusão; renomear contas (`PATCH /api/accounts/{id}`). README: seção "Rodar o app" (make db-up, make api, make web).

## Review Focus
1. API fora do ar / erro 4xx-5xx → toast com a mensagem pt-BR, telas não quebram.
2. Mês sem dados e banco vazio (primeiro uso) → estados vazios com chamada para importar.
3. Resposta de pergunta enquanto outra está em voo (duplo Enter) → não responde duas vezes.
4. Valores negativos (estornos) e categorias com total negativo no mês → formatação e barras corretas.
5. Tela estreita (375 px) → sidebar vira menu, tabelas com rolagem horizontal própria.
