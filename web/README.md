# web

App React (Vite + TypeScript + Tailwind v4 + shadcn/ui) que consome a API em `backend/`.

```sh
npm install
npm run dev      # http://localhost:5173, /api → http://127.0.0.1:8080
npm run build    # tsc + vite build
npm run lint     # oxlint
npx vitest run   # testes de lógica pura (formatação, api)
```
